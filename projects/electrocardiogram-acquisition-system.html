Junior Design Project

Electrocardiogram Acquisition System

Analog front end, PCB design, UART data path, Python visualization

I am using this case-study scaffold to document an ECG signal acquisition PCB and firmware/software path. I do not claim medical-grade performance or certification.

Overview

I acquired differential heartbeat signals from arm electrodes, conditioned the analog signal, converted it with a PIC24 ADC, transmitted data over UART, and graphed the output in Python.

Technical Implementation
